Overview

Custom Carpentry done right

Carpentry is the heart of what we do. From rough framing to the finest finish trim, we build the custom details that make a house feel like yours — built-in shelving, window seats, mantels, wainscoting, and more.

If you can think it, we will build it. When a project does not fit a standard category, this is where it lives: true custom work, done by hand.
